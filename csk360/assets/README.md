# Bundled assets

## robot.blend (starter character body)

"RobotExpressive" by Tomás Laulhé ([Quaternius](https://quaternius.com)),
released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
Facial morph targets added by Don McCurdy. Taken from the three.js examples
(`examples/models/gltf/RobotExpressive`, release r170).

Converted for CSK360 by `tools/make_robot.py`: posed into CSK360's rest pose
(arms down), joined into one mesh weighted to CSK360's bone names, scaled to
1.7 m and stored with the joint positions CSK360 builds its skeleton from.

CC0 means no attribution is required; we credit the author anyway. If you like
the robot, consider supporting Quaternius.
